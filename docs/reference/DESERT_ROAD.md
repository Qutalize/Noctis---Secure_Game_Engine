# 荒野を起点にした旅のPV

荒野のデモに続き、草原、雨の森、工場地帯を一つの散策ルートにした。通しPVはこの順に内陸を抜け、海岸のデモへつないで外海で終える構成を想定する。

## 添付PVで観察した構図

『UNCOVERED: FINAL FANTASY XV Trailer [JP]』の2分以降から代表フレームを読み取った。時刻は添付MP4内の位置。

| 参考位置 | 確認した画面 | 自作PVでの使い方 |
| --- | --- | --- |
| 2:30付近 | 暗い空の下で人工物の水平線が奥へ延びる | 工場地帯は配管や足場で長い消失点を作り、小さな作業灯の反射で奥行きを出す |
| 3:06付近 | 車と乾いた風景が逆光で重なる | 荒野は二車線道路の向こうに岩棚を重ね、進行方向の低い光で締める |
| 3:41付近 | 開けた水辺、草、樹幹、遠くの大きな輪郭 | 湿地は水面近くからヨシと水路の反射を見せ、遠景に工場の輪郭を先に出す |
| 3:57付近 | 船の周囲の航跡と水平線が見える | リゾートの桟橋から船へつなぎ、航跡を残して外海へ進む |

原映像の素材は配布用データに含めず、構図、光の方向、地形の切替、移動の見せ方を参照した。

## 荒野デモ

赤い岩棚の間を抜ける二車線道路、風化したアスファルト、黄色のセンター線、路肩の低木、電柱と架線を配置した。地形の区画ごとに独立したglTFを読み込む。道路の節点と岩棚の配置は `assets/models/desert/route.json` に保存し、Codexで制作した形状を書き出す。土と路面はPoly Havenの写真材質、路肩の大きな岩は既存のCC0岩壁モデルを使う。岩棚の各層は再利用した砂岩の画像に異なる色係数を設定し、路面・赤土は変換時に512角へ縮小。離れた材質の法線を弱める。空は海岸デモと同じ手続きシェーダーを使う。出典は [アセットクレジット](../../assets/CREDITS.md) を参照。

`DesertRoad.exe` の横に `shaders` と `desert-assets` を置く。WASDで移動、Shiftで走る、Tabでマウス視点を切り替え、Rで開始地点、Escで終了。歩行範囲は道路とすぐ外側の路肩。道路モデルと視点の高さは同じ節点を使う。散策は対応環境で4x MSAA。PVは俯瞰、道路すれすれの移動、峠を望む逆光の3カットを12秒で収録する。

標準Windows ActionsではRelease、道路の補間と歩行境界、撮影カメラ288点、WARPでの4x MSAA、H.264映像の全体デコードを確認する。音の調整は通しPVの工程で扱う。実機GPUでの性能と操作体験は未評価。

## 検証結果

`e23bbf9` で荒野のRelease、道路の補間、歩行境界、カメラ288点、4x MSAA、PVの全体デコードが成功。960×540、24 fps、12秒のMP4は4,289,499バイト。SHA-256は `C04ACA1D0FD787669240663FBCEC306A6B6B2F727E07B060477A4CE7449EE209`。配布セットでは4モデルの参照画像と頂点データを照合した。 [作業ブランチの実行](https://github.com/Qutalize/Noctis---Secure_Game_Engine/actions/runs/44251726500)

最初の収録では岩棚が単色の段に見え、遠い路面で細かな模様が強く出た。砂岩の写真材質、層の輪郭、粗い画素での法線減衰を加えて再撮影した。岩棚の形状と空には簡略化が残る。現在の散策には車両操作はなく、PVの道路沿いの移動はカメラで表現している。

## 通しPVの段取り

| 順番 | 主な見せ場 | 次の場面へのつなぎ | 状態 |
| --- | --- | --- | --- |
| 1. 荒野 | 岩棚、道路、道沿いの休憩所 | センターラインから草原の道へ | DesertRoad |
| 2. 草原 | 尾根が重なる谷、写真アトラスを使った草、曲がる道 | 開けた斜面から林冠の下へ | InlandTour |
| 3. 雨の森 | 濡れた林床、雨粒、谷の霧、休憩小屋 | 雨の森を抜けて工場へ入る | InlandTour |
| 4. 工場地帯 | 波板の建屋、タンク、煙突、頭上の配管と作業灯 | 照明をたどり、沿岸の木の桟橋へ | InlandTour |
| 5. リゾートと外海 | 固定構図で昼から薄暮、桟橋への移動、出航と泡の航跡 | 船を追って沖へ向かい、水平線で終える | SunsetWalkの通しPV用収録 |

50秒の通しPVは三つのデモの収録を編集する。0秒で荒野、12秒で草原、16秒で雨の森、20秒で工場、24秒で海岸へ移る。海岸では5秒間、位置・向き・画角を固定して昼から薄暮へ移す。その画角からカメラを曲線で下ろし、38秒で船が出航する。出航後は船尾を起点に水面シェーダーで航跡を描く。船とカメラの移動は撮影用の軌道。映像には新規に作曲した器楽曲と、風・雨・波・カモメの合成音を使う。

標準Windows ActionsではWARP・4x MSAAで海岸編624フレームを収録し、固定区間のカメラ姿勢、画素差、移動と出航の軌跡を数値で検査する。別ジョブで三章を24 fpsに揃えて結合し、H.264/AACの全編をデコードする。[撮影コード](../../game/sunset/Main.cpp) · [編集と音源の生成](../../tools/sunset/build_journey.py)

`6e288a5` は50秒、960×540、24 fps、1,200フレーム。海岸の最初の121フレームでカメラ姿勢が一致し、昼と薄暮の画素の99.93%でRGBのいずれかが12階調より大きく変わった。船の開始点と終了点の水平距離は83.39m。MP4は14,452,659バイト。 [収録と全編デコードの結果](https://github.com/Qutalize/Noctis---Secure_Game_Engine/actions/runs/44318610907)

## 内陸デモ

`InlandTour.exe` の横に `shaders` と `inland-assets` を置く。WASDで移動、Shiftで走り、Tabでマウス視点を切り替える。1・2・3で草原・雨の森・工場に移動し、Escで終了。散策は経路上を進む。対応環境の散策と撮影で4x MSAAを使う。

内陸の前後方向の散策範囲を200mから980mへ拡張した。草原の初回試写で黒い斑点が出たため、草の写真アトラスを広い面に貼る方式をやめ、スキャン素材の形状とUVを保った9種類の草を配置した。遠景の起伏を途切れさせず、草地を大きな色むらと近景の細かな草で構成した。森は約350mの区間に樹木、林床と休憩小屋を置いた。レンダラーで雨粒、曇天、遠景の霧と濡れた地面を表現する。工場には複数の建屋群、タンク、配管と遠くの煙突がある。[配置データ](../../tools/sunset/inland-layout.json) · [地形・植生モデル](../../tools/sunset/build_landscape.py) · [素材クレジット](../../assets/CREDITS.md)

12秒の内陸編は谷の広角、雨の森の人の目線、工場への進入へ切り替わる。人物には実寸のCC0モデルの固定ポーズを使った。荒野の休憩所、草原の道、森の休憩所付近、工場、海岸の遊歩道・ヴィラ・釣り場・レストランに配置した。内陸編単体は無音。通しPVの編集で音を加える。人物の歩行アニメーションと会話は後続。
