# 荒野を起点にした旅のPV

今回の実装は荒野の章。海岸の既存デモを旅の終盤へ使い、荒野から湿地、工場地帯、リゾートの桟橋、海上へ向かう構成を想定する。

## 添付PVで観察した構図

『UNCOVERED: FINAL FANTASY XV Trailer [JP]』の2分以降から代表フレームを読み取った。時刻は添付MP4内の位置。

| 参考位置 | 確認した画面 | 自作PVでの使い方 |
| --- | --- | --- |
| 2:30付近 | 暗い空の下で人工物の水平線が奥へ延びる | 工場地帯は配管や足場で長い消失点を作り、小さな作業灯の反射で奥行きを出す |
| 3:06付近 | 車と乾いた風景が逆光で重なる | 荒野は二車線道路の向こうに岩棚を重ね、進行方向の低い光で締める |
| 3:41付近 | 開けた水辺、草、樹幹、遠くの大きな輪郭 | 湿地は水面近くからヨシと水路の反射を見せ、遠景に工場の輪郭を先に出す |
| 3:57付近 | 船の周囲の航跡と水平線が見える | リゾートの桟橋から船へつなぎ、航跡を残して外海へ進む |

原映像の素材は配布用データに含めず、構図、光の方向、地形の切替、移動の見せ方を参照した。

## 荒野デモ

赤い岩棚の間を抜ける二車線道路、風化したアスファルト、黄色のセンター線、路肩の低木、電柱と架線を配置した。地形の区画ごとに独立したglTFを読み込む。道路の節点と岩棚の配置は `assets/models/desert/route.json` に保存し、Codexで制作した形状を書き出す。土と路面はPoly Havenの写真材質、路肩の大きな岩は既存のCC0岩壁モデルを使う。岩棚の各層は再利用した砂岩の画像に異なる色係数を設定し、路面・赤土は変換時に512角へ縮小。離れた材質の法線を弱める。空は海岸デモと同じ手続きシェーダーを使う。出典は [アセットクレジット](../../assets/CREDITS.md) を参照。

`DesertRoad.exe` の横に `shaders` と `desert-assets` を置く。WASDで移動、Shiftで走る、Tabでマウス視点を切り替え、Rで開始地点、Escで終了。歩行範囲は道路とすぐ外側の路肩。道路モデルと視点の高さは同じ節点を使う。散策は対応環境で4x MSAA。PVは俯瞰、道路すれすれの移動、峠を望む逆光の3カットを12秒で収録する。

標準Windows ActionsではRelease、道路の補間と歩行境界、撮影カメラ288点、WARPでの4x MSAA、H.264映像の全体デコードを確認する。音の調整は通しPVの工程で扱う。実機GPUでの性能と操作体験は未評価。

## 検証結果

`e23bbf9` で荒野のRelease、道路の補間、歩行境界、カメラ288点、4x MSAA、PVの全体デコードが成功。960×540、24 fps、12秒のMP4は4,289,499バイト。SHA-256は `C04ACA1D0FD787669240663FBCEC306A6B6B2F727E07B060477A4CE7449EE209`。配布セットでは4モデルの参照画像と頂点データを照合した。 [作業ブランチの実行](https://github.com/Qutalize/Noctis---Secure_Game_Engine/actions/runs/44251726500)

最初の収録では岩棚が単色の段に見え、遠い路面で細かな模様が強く出た。砂岩の写真材質、層の輪郭、粗い画素での法線減衰を加えて再撮影した。岩棚の形状と空には簡略化が残る。現在の散策には車両操作はなく、PVの道路沿いの移動はカメラで表現している。
