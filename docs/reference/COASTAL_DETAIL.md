# 海岸デモのアセット、浅瀬、夜景とPV

桟橋・ヴィラ・遺跡の独立モデルと散策中のAAは [海岸の建築アセット](COASTAL_ARCHITECTURE.md) に記録する。

ガーディナの定点映像と移動映像を参考にした海岸デモの改良。ベースは `db8813c94bcb3f6c7b24b7c19dc83200933f7ae1`。浜から橋を渡り、水上のレストランへ至る位置関係は [海岸デモ](COASTAL_BAY.md) に記録している。

## アセットの由来

前版の海岸地形、建物、家具の形状はCodexが作成したC++の手続き生成。今回は遺跡の土台を構成する岩肌に Rock Face 01、テーブルと椅子に Outdoor Table Chair Set 01、吊り灯りに Lantern Chandelier 01 を使用。モデルと材質はPoly Havenが公開するCC0の既存アセットで、配置・水面と照明・カメラのコードにはCodexを利用。浜の地形や桟橋・ヴィラ・遺跡の上部構造は既存の手続きメッシュを使用する。FFXVの参照画像や動画のデータは配布用アセットに含まれない。

出典と作者は [アセットクレジット](../../assets/CREDITS.md) を参照。CIの `prepare_assets.py` は3モデルのglTF、頂点バッファ、画像を固定URLから取得し、SHA-256を照合する。1KのJPEG画像をPNGに変換し、既存のglTFローダーで読む。吊り灯りは透過ガラスの面を外し、金属フレームと発光部を組み合わせる。

## 描画と撮影

- 浅瀬は岸からの距離を水深の近似に使う。細波の傾きでずらした砂底、色ごとの透過率、屈折による光の集まりを模した模様を合成。遠景と面積の小さな模様は距離やピクセルの微分から減衰させる。水底のジオメトリを光線追跡する方式は使っていない。
- 暖色の照明をテーブル左右とカウンターへ分散した。光は距離と面の向きに応じて減衰する。局所光源の遮蔽や多重反射は未計算。
- PVは位置と注視点を別々の三次エルミート曲線で補間する。高所の広角から浜へ下がり、浅瀬を振り返ってからヴィラの横を通り、レストラン内を斜めに抜ける。20秒、24fpsの隣接フレーム間で移動量と向きの連続性を検査する。
- 収録時は1920×1080で描画して、2×2の平均で960×540へ縮小する。細い梁、家具、手すりの縁を収録で比較できるようにした。散策デモの通常描画は960×540。

## 比較の再現

Windows標準Actionsが、前版の描画・シーンを固定コミットから取り出し、新版と共通の撮影コードでビルドする。広角、浅瀬、遺跡、夜の食事席の各カメラの位置・向き・波の時刻・光の段階は固定する。

| 出力の接尾辞 | 撮影条件 |
| --- | --- |
| before | 前版を960×540で描画 |
| after | 新版を960×540で描画 |
| after-aa | 新版を1920×1080で描画、960×540へ縮小 |

`revision-comparison.json` の数値は画素差の大きさを表す。好みやリアリズムの評点ではない。映像は音声込みで全フレームをデコードする。実機GPUのフレーム時間と聴感は別途計測が必要。

| 固定構図 | 波の時刻 | 光の段階（0=昼、1=薄暮） | 前版→新版、RGB差8超 | 新版のAA有無、RGB差3超 |
| --- | ---: | ---: | ---: | ---: |
| 広角 | 0秒 | 0.00 | 21.57% | 8.40% |
| 浅瀬 | 4秒 | 0.12 | 55.83% | 8.70% |
| 遺跡 | 7秒 | 0.33 | 4.41% | 5.19% |
| 食事席 | 19秒 | 0.97 | 59.44% | 6.84% |

初回の比較画像では、岩壁に旧地形のシルエットがかかり、食事席の手前を桟橋の柵が横切っていた。島の前景を開け、食事席の柵を取り除き、梁と吊り灯りの位置を合わせた。最終候補 `ad5af182ad99f6052d4f63286fd00f4ae3845264` の比較画像で岩の層、椅子・テーブル、暖色光が床と天井に落ちる様子を確認した。 [比較の標準Actions](https://github.com/Qutalize/Noctis---Secure_Game_Engine/actions/runs/44232291230)

20秒、480フレームのH.264とステレオAACを最後までデコードした。検証したMP4は6,027,311バイト、SHA-256は `2E3FAA481E3F6A3FA437DB1BC65098D615BAA54559B1C9B1EFAA3AC84ED1BD13`。固定視点で0.62秒進めた海面は、指定領域の35.68%でRGB差が4を超えた。散策の経路確認、カメラの連続性、既存カード試験も同じ標準Actionsで成功した。

Windows版で散策する場合は `SunsetWalk.exe` の横に `shaders`、`coastal-assets`、既存の2つのWAVを置く。ビルドから再現する場合、Release出力先に `python -B tools/sunset/prepare_assets.py build-ci/Release/coastal-assets` を実行する。モデル取得と画像変換にはネットワークとFFmpegが必要。CIの配布用フォルダーは取得・変換済みで、散策中のネットワーク取得は行わない。
