# 夕景リゾートPV

## 12秒の構成

| 時刻 | カメラ | 見せる内容 |
| --- | --- | --- |
| 0.0–4.5秒 | 海上からの広角 | 低い夕日、雲、揺れる帆船、海に張り出したリゾート |
| 4.5–8.5秒 | 桟橋へ寄る | 岸際の泡、連続するアーチ、パラソル、海上を横切るカモメ |
| 8.5–12.0秒 | アーチ脇からの近景 | 石積み、柱の台座・柱頭、床の目地、テラスと客室 |

海面の高さと傾きは同じ3方向の波形から計算する。位相を位置と時刻で緩やかにずらし、反射の明るい点が等間隔の列に見えにくくした。空の色と夕日の方向を反射ベクトルで近似し、浅い視線角ではフレネル項で空の色を強くする。遠景では傾きと反射の鋭さを落とし、波頂と桟橋の外周近くに泡を加えた。空の雲は方向ごとの多段ノイズ、石は色・法線マップと実際の石積み形状で描く。水面の反射に使うのは空と太陽の近似で、建物や帆船の鏡像は扱っていない。

出力は960×540、24 fps、288フレームのH.264＋AAC。波音とカモメの音は、同じシードで再生成できるステレオの合成音。映像で見える鳥の位置と一羽ずつ対応する音響処理は入れていない。ポリゴン、石の画像、波音と鳥の音はすべてプロジェクトのソースで生成する。FFXVの参考PVは遠景から寄りへ切り替える構成の参考とし、映像・音源・モデルは取り込んでいない。

## 実行と再生成

`SunsetWalk.exe`、`shaders` ディレクトリ、`sunset-ambience.wav` を同じ場所に置く。WASDで桟橋を歩き、Tabでマウス視点、F2で簡素／詳細の切替、Rで視点を戻し、Escで終了する。テラスと客室は撮影用の背景。比較用の歩行範囲は各条件で共通。

公開リポジトリの標準 `windows-2025` ActionsでReleaseをビルドし、WARPで収録する。中間フレームはランナーでのみ生成し、成果物はMP4、比較PNG、計測CSV・JSONと再生用ファイルを5日間保持する。再生成の入口は次のとおり。

```powershell
cmake -S . -B build-ci -G "Visual Studio 18 2026" -A x64 -DGAME_PROFILE=all -DBUILD_SUNSET_WALK=ON
cmake --build build-ci --config Release --target sunset_walk
./build-ci/Release/SunsetWalk.exe --self-test
./build-ci/Release/SunsetWalk.exe --capture sunset-evidence
python -B tools/sunset/verify_captures.py sunset-evidence
./build-ci/Release/SunsetWalk.exe --pv-frames pv-frames
python -B tools/sunset/build_pv.py pv-frames sunset-evidence
```

収録・比較のディレクトリは毎回新しいパスを指定する。MP4作成には `ffmpeg` と `ffprobe` が必要。`build_pv.py` はフレーム数・解像度・時間・音声形式を検査し、MP4を最後までデコードする。

## 3Dアセットの比較条件

広角は0秒、近景は10.5秒を固定する。各カット内では視点・時刻・光・海面・建物の配置を同一にし、桟橋とテラスの石材だけを切り替える。簡素版は平らな面と8分割のアーチ。詳細版は24分割の石造アーチ、下地、柱の台座・柱頭、舗石の目地、色と法線マップを使う。客室、植栽、帆船、パラソルは共通。画素差はRGBのいずれかが8/255を超えた画素の割合。ジオメトリと材質を一緒に切り替えるため、両者を個別に順位づけするには条件を分ける必要がある。

別の比較は広角と詳細素材を固定して時刻だけ0.62秒進め、左側の海面領域の画素差を測る。波・反射・泡を含む時間変化の確認で、各効果の寄与を分離する試験ではない。

## AIの関与

Codexが描画・素材生成・音声合成コード、撮影経路、比較スクリプトと試験の下書きを作成した。課題設定はユーザーの光表現、広角から近景へつなぐ構成、リゾートの動き、近景素材の比較、手法公開時の防御という要件に基づく。初回の収録画像で、水平線まで反射が格子状に並び、近景の石に細かな縞が出た。波の位相・遠景の反射と、石のUV・色・法線を変更して再撮影した。
