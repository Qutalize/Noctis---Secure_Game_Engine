# 海岸デモと20秒PV

既存アセット、浅瀬と夜景、連続カメラ、AAの追加と旧版比較は [海岸デモの画質改良](COASTAL_DETAIL.md) に記録する。

参考はユーザー添付の『FFXV』ガーディナの定点64倍速動画、ドライブスルー動画と画像7枚。定点では青い昼空から照明の点く夜への変化、移動映像では木の桟橋を渡って開放的な水上の食事席へ入る動線を観察した。浜、桟橋、ヴィラ、釣り場、レストラン、水平線の大きな遺跡という空間の関係を、このエンジンの手続き生成で組み直した。添付の映像・画像・音源は参考資料として使い、配布物は独自の形状と合成音で構成する。

| PVの区間 | 撮影する内容 |
| --- | --- |
| 0–5秒 | 上から浜、湾、桟橋、水上の建物と沖の遺跡の位置関係を見る |
| 5–9.8秒 | 木の床へ視点を降ろし、左の釣り場と海の奥行きを見せる |
| 9.8–14.5秒 | 光が暖かくなる中でヴィラと近景の石材を見せ、距離に応じて音楽を強める |
| 14.5–20秒 | 道を進んで水上レストランへ入り、薄暮の空と暖色の灯りを同時に見せる |

## 実装の判断

- 海面は小さなうねりに、風で移動する位置ノイズと、高さの勾配から得た傾きを重ねる。ピクセル当たりの模様の細かさに応じてノイズを抑え、遠景では反射の法線を滑らかにした。泡は桟橋の輪郭から、砂浜に沿って時間と位置で切れる白波へ移した。浅瀬の色と空・太陽の反射を近似している。
- 太陽の高度と方位、空の色、雲、影、海面の反射を一緒に変化させる。薄暮では窓と吊り灯りを明るく描き、レストラン内では一つの暖色フィルライトで床や備品を照らす。時刻は映像用に圧縮した。遮蔽付きの点光源や建物の鏡像は将来の対象。
- 環境音は波とカモメを一つのステレオ音源にし、ヴィラのために弦をつま弾く音色のアルペジオを別に合成した。ゲームのXAudio2とPV合成処理は同じヴィラ距離減衰を使う。音の床面反射や建物による遮音は計算していない。
- 散策はWASD、Tabで視点、F2で石材の簡素・詳細切替、Rで開始位置。釣り場は歩いて近づける桟橋で、魚を釣るゲーム処理は含まない。砂浜・遺跡は景観として描画する。実行ファイルの隣にDXILの `shaders` と生成した `sunset-ambience.wav`、`villa-music.wav` を置く。

## 検証

標準Windows ActionsでReleaseをビルドし、既存の移動・柱・端の判定に釣り場の進入と境界、水上レストランまでの歩行を加えた。WARPで広角と近景のアセットA/B、固定視点・固定光で0.62秒進めた海面、固定視点で午後と薄暮の空の色を確認する。20秒、960×540、24fpsの動画を合成し、映像・音声を全体デコードする。映像のフレームごとのヴィラの音量係数を記録する。A/Bは同一カット内の材質と形状の差を扱い、見た目の嗜好、自然さやリアリズムは画素差から判定しない。

参考動画の観察結果と、空間や波・音をどう作るかの判断を記録した。Codexが試作コードと検証コードを作成し、編集の効果は対象コミットの実行結果に結びつける。

### 実測結果

コミット `7cb042daca580033cc2c4033dd67ec97177867a8` の標準Windows ActionsでRelease、散策経路、WARPの画像比較、480フレームとステレオAACの全体デコード、既存のカード防御回帰が成功した。出力MP4は4,902,289バイト。SHA-256は `72305B9856C0027485F2DE24D52E627D3CED5368133DE8BC3AAF6209CEC8712E`。 [作業ブランチのCI結果](https://github.com/Qutalize/Noctis---Secure_Game_Engine/actions/runs/44228367536)

| 計測 | 結果 |
| --- | --- |
| 素材A/B、RGBの差が8/255を超えた画素 | 広角1.97%、近景51.95%。切替対象は422→5,580三角形 |
| 波の時間差0.62秒、指定海面領域でRGBの差が4/255を超えた画素 | 33.13% |
| 固定カメラの空の平均RGB | 午後148.71→薄暮38.79（0–255） |
| PV内のヴィラ音楽の音量係数 | 0.0044–0.4201 |

初回は音楽が目標の音量係数に届かなかったため、減衰距離を調整して再実行した。試写後に浜の岩の間隔と形を変え、ヤシの根元を地形の高さに合わせ、レストランの暖色光を強めた。最終MP4で広角、桟橋、ヴィラ近景、薄暮の店内を目視した。描画はWARPで検証した。ハードウェアGPUでの性能とインタラクティブ音声の聴感は未測定。
