# 海岸の建築アセットと散策時のアンチエイリアシング

荒野から出航へ向かう通しPVは [旅のPV構成](DESERT_ROAD.md) を参照。

舞台の位置関係と実時間の歩行範囲は [前版の海岸デモ](COASTAL_DETAIL.md) に基づく。今回の目的は、遠景の輪郭と寄ったときの材質を両立させ、映像・散策のどちらでも細い輪郭を読み取りやすくすること。

## モデルと材質

| 対象 | 独立モデルの作り込み | 適用する写真材質 |
| --- | --- | --- |
| 木の桟橋・釣り場 | 板の継ぎ目、桁、杭、斜めの補強、たるませた綱、金具 | Wood Planks Grey の色・法線・AO・粗さ |
| ヴィラ | 石の基礎と角石、壁の開口、奥まった窓、枠と窓台、瓦屋根と棟瓦 | Large Sandstone Blocks 01、Coast Sand 01、Roof 09 |
| 沖の遺跡 | 基壇、溝のある柱身、石の継ぎ目、欠けた柱頭、断続的な梁 | Large Sandstone Blocks 01 と前版の Rock Face 01 |
| 浜と浅瀬 | 砂の粒状感、岸辺の法線、水深と視線に応じる砂底 | Coast Sand 01 |

3モデルの寸法と配置は `assets/models/coastal/architecture.json` に保存する。Codexで新規に作った形状をCIでそれぞれ独立したglTFとして書き出す。実行時は既存のglTFローダーで読み込み、モデルと材質はBlender等でも個別に開ける。写真材質はPoly Havenの既存CC0を使用し、色をsRGBから線形へ変換してから照明を計算する。照度や色の扱いを変更する範囲は海岸デモの該当素材へ限定した。形状の制作方法と外部素材の出典は [クレジット](../../assets/CREDITS.md) に記載。

シーンで計算する雲、砂浜の地形、植生と水の光学は前版を土台にした近似。ガーディナの参考映像は見た目と空間構成の参照に使用した。

## AAと比較条件

散策は対応環境で4x MSAA。メイン描画用の色・深度とPSOを4サンプルにし、単一サンプルのバックバッファへDX12のResolveSubresourceで解決する。シャドウマップは1サンプル。利用可否は色・深度両方の品質レベルから判断し、タイトルバーにサンプル数を示す。通常のレンダラー呼び出しは既存の1サンプル。PVは1920×1080で描画し、2×2の画素平均で960×540へ縮小する。

| 出力 | 条件 |
| --- | --- |
| `before` | 前版 `1219ab9` を960×540で描画 |
| `after` | 新版を同じカメラ・波の時間・光の段階で960×540に描画 |
| `after-msaa` | 新版を960×540、4x MSAAで描画・解決 |
| `after-aa` | 新版を1920×1080で描画して960×540へ縮小 |

固定構図は広角、浅瀬、桟橋、ヴィラ、沖の遺跡、夜の店内の6つ。SSAAとMSAAの差はそれぞれ新版の1サンプル画像を基準に測る。数値は画素差で、質感やリアリズムは画像で観察する。散策用MSAAはWARPでも実際の解決経路を通す。水や光のフレーム間のちらつきには材質側のフィルタも影響する。

| 固定構図 | 波の時間 | 光の段階（0=昼、1=薄暮） | 前版と新版のRGB差8超 | 新版でMSAAを有効にしたRGB差3超 |
| --- | ---: | ---: | ---: | ---: |
| 広角 | 0秒 | 0.00 | 28.65% | 5.25% |
| 浅瀬 | 4秒 | 0.12 | 69.61% | 4.92% |
| 桟橋 | 6秒 | 0.21 | 47.92% | 6.74% |
| ヴィラ | 11.5秒 | 0.59 | 37.18% | 4.35% |
| 遺跡 | 7秒 | 0.33 | 2.52% | 0.88% |
| 店内 | 19秒 | 0.97 | 5.76% | 5.56% |

画像では桟橋の綱、板の木目、ヴィラの窓の奥行き、欠けた柱を確認した。MSAAをオンにした桟橋では、手すりの細い綱と杭の縁が滑らかになった。表面の細かなノイズや規則的な木目の反復、単純化した背景の雲と植生は残る。実機のリアルタイム性能は未計測。 [同一条件の標準Actions](https://github.com/Qutalize/Noctis---Secure_Game_Engine/actions/runs/44242596088)

コミット `950220faaa9a079e3d07c9c4a94748c072f8f548` の標準Windows Actionsで、前版と新版のRelease、歩行・曲線カメラの検査、6構図の比較、MSAAの解決、PV全体のデコード、既存のカード防御回帰に成功した。20秒・480フレーム・ステレオAACのMP4は7,102,683バイト。SHA-256は `E62B4327243D38DD33F43845436B24EB886E2E34942C3DBD67550ADC6D796CDF`。写真材質を入れた初回のMP4は8 MiB上限を超えたため、映像の最大ビットレートを2.8 Mbpsに設定して収録し直した。散策セットは6モデルと依存画像・DXIL・WAVの参照を照合した。 [最終の作業ブランチCI](https://github.com/Qutalize/Noctis---Secure_Game_Engine/actions/runs/44243986756)

## 再現方法

標準Windows Actionsの `sunset-evidence` から、実行ファイル、`shaders`、`coastal-assets`、2つのWAVを取得して同じ階層に置く。モデルを書き出す場合は `python -B tools/sunset/prepare_assets.py build-ci/Release/coastal-assets` を実行する。使用する画像は取得時にSHA-256を照合する。
